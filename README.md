# yajuugengo (野獣言語)
Node.js上で動作する、語録をベースにしたスクリプト言語です。
独自のトランスパイラにより、日本語（淫夢語録）をJavaScriptに変換して実行します。
## 構文リファレンス (Syntax)
yajuugengoでは、以下の語録を使用してプログラムを記述します。
### 1. プログラムの根幹

| 語録 | 役割 | JavaScript相当 |
| :--- | :--- | :--- |
| `24歳、学生です。` | プログラムの開始 | `async function main() {` |
| `王道を往く` | プログラムの終了 | `}` |

### 2. 変数と出力

| 語録 | 役割 | 使用例 |
| :--- | :--- | :--- |
| `やりますねぇ！` | 変数宣言 (let) | `やりますねぇ！ temp = 36.4` |
| `ブッチッパ！` | 標準出力 | `ブッチッパ！ 「やりますねぇ！」` |

### 3. 条件分岐とループ

| 語録 | 役割 | 使用例 |
| :--- | :--- | :--- |
| `アアーッ！ (条件)` | 条件分岐 (if) | `アアーッ！ (temp > 37.0)` |
| `おわり` | ブロックの終了 | `}` |

### 4. 数値・演算定数

| 語録 | 役割 | 値 / 記号 |
| :--- | :--- | :--- |
| `いいよ！来いよ！` | 定数 | `114514` |
| `イクイク` | 定数 | `1919` |
| `菅野美穂` | 加算演算子 | `+` |

### 5. 例外処理 (Error Handling)
エラーが発生しそうな箇所を保護し、発生時に特定の処理を行います。
- **開始:** `✝悔い改めて✝` (try)
- **捕捉:** `これもうわかんねぇなぁ。` (catch)
- **送出:** `ンアッー！` (throw error)
